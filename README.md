# НИПТ — превью правок лендинга (Геномед)

Две версии для сравнения, переключаются полосой «Версии» вверху страницы:

- **Исправленная** — https://varvarayukhina.github.io/nipt-review-genomed/
- **Наглядная · путь ДНК** — https://varvarayukhina.github.io/nipt-review-genomed/naglyadnaya.html

Основа — наш прототип от 16.09 (`~/Downloads/НИПТ-прототип/index.html`), не страница с genomed.ru.
Страницы закрыты от индексации (`noindex, nofollow`).

## Что изменено в обеих версиях

**Порядок блоков — для пациента** (как в MEMA): что это, для кого и когда → почему исследование безопасно →
что вы получаете → точность → панели и цены → сравнение → подбор панели → как проходит → ограничения →
почему Геномед → вопросы → **для врачей** → запись.

**Новый блок «Почему исследование безопасно».** Отвечает на замечание гендиректора «почему он безопасный?»
и даёт схему «взяли кровь → получили результат»: плацента → кровь мамы → взятие крови → секвенатор → заключение.
Факты взяты с этой же страницы, новых нет.

**Раздел «Для врачей» в конце.** Туда переехали:
- PPV/NPV и порог 1 : 100;
- «Как устроен анализ»;
- рекомендации ACOG, SMFM, ISPD, ACMG;
- источник показателей выявляемости.

В текстах для пациента аббревиатур и сносок больше нет.

**Вычитка: без жаргона, разговорных оборотов и повторов.**
- «забор крови» → «взятие крови»;
- «общий пул ДНК» → «ДНК разных плодов в крови матери»;
- «если удобнее голосом» → «удобнее по телефону»;
- «место сдачи» → «ближайший медицинский офис»;
- «порог делит результат надвое» → «граница между высоким и низким риском»;
- «лишняя 21-я хромосома» → «дополнительная копия 21-й хромосомы»;
- «в цене ошибки» — убрано; «ни амниоцентеза, ни биопсии хориона» → «без амниоцентеза и биопсии ворсин хориона»;
- «Восемь дней ожидания — самая длинная неделя…» → «Результат — через 8 дней. Заключение врач-генетик разбирает вместе с вами»;
- «Одна пробирка вместо процедуры, которую многие боятся» → «достаточно взять кровь из вены — без инвазивной процедуры»;
- «тест» → «исследование» в описаниях;
- «не диагноз» убран из описательных блоков: остались плашка «Важно», два ответа на прямые вопросы о высоком риске и юридический дисклеймер внизу;
- фразы про интерфейс («первая колонка закреплена, таблица тянется вбок») убраны;
- внутренние пометки для заказчика («на странице он смотрелся бы весомее…») убраны.

**Исправления по смыслу.**
- Квиз: «носительство у родителей» → «у будущей мамы». Скрининг носительства делают только маме.
- Носительство: «при совпадении мутаций у обоих родителей» → «если носителями вариантов в одном и том же гене окажутся оба родителя: тогда вероятность заболевания у ребёнка — 25 %».
- «Геномед» без кавычек и склонения: «ООО Геномед», «врач-генетик лаборатории Геномед»; подпись «Фото — из медиатеки Геномеда» снята.

**Убраны служебные слои прототипа:** демо-режим с подсказками, журнал «что изменено», блок-заглушка отзывов.

**Только для превью, на сайт не переносится:**
- полоса «Версии»;
- окно «Выберите удобный способ связи» (Telegram, WhatsApp, MAX, телефон) вместо сайтовой формы `#modal-callback` — на genomed.ru эту роль выполняет штатная форма темы.

## Наглядная версия — дополнительно

- **Интерактивный путь ДНК** — единственная анимация на странице. Схема из пяти этапов: плацента → кровь мамы (ДНК плаценты среди ДНК мамы) → пробирка (плазма и клетки крови, 20 мл) → секвенатор → прочтения по хромосомам (13, 18, 21).
  - Управление: ползунок, перетаскивание самой картинки, нажатие на этап или стрелки клавиатуры.
  - Поведение: схема идёт за пальцем 1:1, после отпускания докатывается по инерции до ближайшего этапа.
  - Учтён режим «меньше движения».
- **Мобильная доводка:**
  - эффекты наведения только для мыши (на телефоне они «залипали» после тапа);
  - отклик кнопок на нажатие;
  - поля формы 16 px, чтобы iOS не увеличивал страницу;
  - отступы под «чёлку»;
  - цвет строки браузера.

## Открытые вопросы

- **Юлия:** 20 или 10 мл крови (на странице 20); носительство в расширенной панели; 6 микроделеций; срок экспертной; двойня в стандартной панели и старше; источник цифры «> 99 %».
- **Год:** на странице НИПТ «с 2013 года в медико-генетической диагностике», на лендинге Геноскопа МГЦ Геномед — «с 2007 года». Нужно сверить.
- **Отзывы:** блок снят до появления реальных высказываний с указанием площадки.
- **Микроделеции:** полный перечень 31 синдрома; на странице названы 13.
- **Фото для «Где сдать»:** нужны кадры партнёрского центра и выезда медсестры.
- **Боевая страница:** цели Метрики, noindex и 301 с тестового адреса, og:image.
- **Подвал WordPress:** строка про ПроДокторов и соцсети — правка шаблона сайта.
